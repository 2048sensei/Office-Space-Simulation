快捷键 & 使用技巧

拖动家具
按住鼠标/手指拖动，靠近墙或其它家具时自动吸附
缩放
选中后拖动 8 个白色手柄；桌子会吸附到标准规格
旋转
拖顶部圆点、按 R，或 Shift + 点击家具
复制
Ctrl + D，或按住 Ctrl 拖动
删除
Delete / Backspace
微调位置
方向键移动 5cm，Shift + 方向键移动 1cm
撤销 / 重做
Ctrl + Z / Ctrl + Shift + Z
测距
按 M 或点「测距」，画布上点击两点
缩放视图
+ / -，0 恢复
取消
Esc 取消选中 / 退出测距

提示：把导出的 JSON 文件直接拖进画布即可导入。
